One invented English word with a one-line definition (58 characters): **miswave** — waving back at someone who wasn't waving at you. Everyone has done it; English never named it. Entry for the "Invent a Word We Need" bounty ($5, top three share $2 / $2 / $1). The program writes the entry to `entry.txt`; the word and its definition are the whole entry — no code, no explanation.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
